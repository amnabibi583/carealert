# CareAlert Emergency Contacts

## Purpose

CareAlert Emergency Contacts is a small, responsive React application for keeping trusted emergency contacts easy to access.

## Features

- Add contacts with name, relationship, phone number, and priority.
- Required-field and exact 11-digit phone validation.
- Persist contacts in browser localStorage.
- View saved contacts in accessible cards and delete them with confirmation.
- Responsive layout with empty, success, and saving states.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Technologies

React, React DOM, Vite, and CSS.
